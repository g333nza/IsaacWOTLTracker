# Isaac Secrets Tracker

Find out which secrets you're still missing in **The Binding of Isaac: Wrath of the Lamb** and **Eternal Edition**, and how to unlock each one.

**Use it here: https://g333nza.github.io/IsaacWOTLTracker/**

## How to use

1. Open the page.
2. Choose your save file (or drop it on the page).
3. Browse what's missing, filter by category, or search by name or `#number`.

## Supported save files

- `so.sol`: the original Flash version
- `isaac_eternal_save.sol`: a recompiled version

The page detects which format you loaded.

## Privacy

Your save file is read entirely in your browser. Nothing is uploaded or sent anywhere.

## Notes

- Secret names and order follow the community wiki's Secrets page. A few wiki entries are disputed, and where they differ from the game's own data, the entry says so.
- Fan-made tool. Not affiliated with or endorsed by the creators or publishers of The Binding of Isaac.
